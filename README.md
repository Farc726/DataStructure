## 编译运行

单个源文件直接用 gcc / g++ 编译即可，例如：

```bash
gcc 线性表/链表.c -o 链表
g++ 线性表/顺序表.cpp -o 顺序表
```

编译产物统一输出到 `output/` 目录（已在 `.gitignore` 中忽略）。
